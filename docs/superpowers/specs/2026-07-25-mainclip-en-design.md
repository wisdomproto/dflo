# 병원 소개 영상 영어판 (MainClipEN) — 설계

작성일: 2026-07-25
상태: 승인됨 (사용자 승인 2026-07-25)

## 목표

병원 진료과정 소개 영상(4분 5초)의 **영어판**을 만들어 홈페이지 `/en/` #clinic 섹션에 연동한다.
화면 텍스트와 나레이션 모두 영어. 태국어판(MainClipTH) 자산을 최대한 재활용한다.

## 배경

- 현재 홈페이지 #clinic 섹션은 **YouTube 임베드**(`WkBRUFXOGPo`)로 한국어 영상을 전 언어에 노출한다.
- 태국어판(`MainClipTH`)이 이미 만들어져 있고, **큐 91개·나레이션 39줄이 초 단위로 확정**돼 있다.
- 영어판은 이 구조에 **텍스트만 갈아끼우는 작업**이지, 처음부터 만드는 일이 아니다.

## 산출물 (신규 3파일)

```
remotion/src/mainclip/
├── cues.en.ts          큐 91개의 영어 텍스트 (타이밍·좌표는 cues.ts 그대로) + 엔딩 큐 신규
├── narration.en.json   나레이션 39줄 영어 (from/to 윈도우는 narration.json 그대로) + 엔딩
└── MainClipEN.tsx      MainClipTH 복사, en 소스 참조, Root.tsx 등록
```

번역 분량: 큐 텍스트 슬롯 약 140개 (subtitle 40 · label 15 · callout 8 · qcard 6 · qbar 6 · circle 6 · number 6 · title 2 · chip 2) + 나레이션 39줄.

## 엔딩 7초 재설계 (태국어판에 없는 구간)

한글 원본의 마지막 7초는 **"네이버에서 187 성장클리닉 검색"** 유도인데, 영어권에는 통하지 않는다
(한국어로 검색할 리 없고, 검색해도 한국 결과가 나온다). 도메인 직접 노출로 교체한다.

| 시각 | 한글 원본 | 영어판 |
|---|---|---|
| ~239–242s | 검색창 `187_` + "검색창에서 187 성장클리닉을 검색해보세요" | 검색창 목업을 불투명 배너로 덮고 **"Visit dr187growup.com"** |
| ~242–245s | 폰/PC 목업 (한글 화면) | 목업 유지 + **"Free height prediction · dr187growup.com/en"** |

베이크된 한글은 `callout` 큐의 `banner: true`(불투명 배너)로 덮는다 — **태국어판이 이미 쓰던 기법**
(예: 무릎 X-ray 라벨, 아이 나이 라벨)이라 새 기술이 아니다.

## 작업 순서

1. **번역** — 큐 텍스트 + 나레이션을 영어로. 화자 = 남성 한국인 의사, professional 톤.
2. **TTS** — `gen-tts-seq.mjs` + `ELEVEN_VOICE_ID_EN`으로 연속 생성(한 목소리 유지), 각 줄을 원래 윈도우에 배치.
3. **믹스** — 더빙 + 기존 배경음악 스템.
4. **렌더** — 컷별 렌더 → 사용자 확인 → 전체 결합.
5. **연동** (승인 후) — R2 업로드 + 홈페이지 `/en/` #clinic 섹션 연동.

## 알려진 제약

- **영어는 한국어보다 길다.** 같은 내용도 문장이 길어져 원래 윈도우(예: 2.8초)를 넘칠 수 있다.
  1순위 대응 = **간결한 번역**, 그래도 넘치면 `atempo`로 속도 미세조정(태국어판과 동일 방식).
- **립싱크는 하지 않는다** (사용자 결정). 원장 입모양은 한국어라 더빙식으로 어긋난다.
  추후 필요하면 LatentSync로 별도 작업 가능.
- **의료 카피** — 번역문은 원장/전문 감수 대상. 특히 치료 효과 서술은 의료광고법 톤 유지.
- 대용량 자산(클린 영상·TTS·렌더 산출물)은 gitignore. 커밋 대상은 소스 3파일뿐.
