**의뢰**: 연세새봄의원 187 성장클리닉 소개 리플렛 전면 재디자인
**작성**: 2026-07-26

---

## 1. 왜 다시 만드는가

현재 리플렛은 A4 55페이지 PDF를 웹으로 옮긴 것이다. 두 가지 문제가 있다.

**한 권에 독자가 둘이다.** 환자 부모용 내용과 파트너·에이전트용 「글로벌 사업」(7페이지)이 섞여 있다. 부모는 관계없는 장을 넘겨야 하고, 파트너는 앞의 25페이지가 필요 없다.

**화면에서 읽히지 않는다.** A4 절대좌표 위에 텍스트를 얹은 구조라 화면 폭에 맞춰 흐르지 않는다. 폰에서는 페이지 전체가 축소돼 글자가 작아진다. 번역이 길어지면 박스를 넘쳐 폰트를 자동으로 줄이고 있다.

이번 리플렛은 **해외 부모용 한 권**으로 좁힌다.

---

## 2. 독자와 사용 맥락

**해외에 사는 부모.** 아이의 키를 걱정해 한국의 성장 클리닉을 찾고 있다. 실제 문의가 온 곳은 호주·싱가포르·말레이시아·영국·인도네시아다.

**두 가지 경로로 본다.**

| | |
|---|---|
| **화면 (주)** | 문의해 온 부모에게 WhatsApp으로 링크를 보낸다. **폰에서 본다.** |
| **인쇄 (부)** | 낱장 A4로 출력해 상담 때 건네거나 해외 오피스에 비치한다. |

한 소스에서 둘 다 나와야 한다. 낱장이므로 페이지 수 제약(4의 배수)이나 펼침면 구성은 없다.

**이 사람들이 실제로 묻는 것** — 문의 대화 6건에서 추출했다. 빈도순이다.

1. 비용 (6/6) — *이번 리플렛에는 넣지 않는다*
2. 한국에 가지 않고 시작할 수 있나 (4/6)
3. 가면 며칠 걸리나 (3/6) — "관광객이라 여러 군데 못 다닌다"
4. 현지에서 X-ray를 찍어도 되나 (2/6)
5. 우리 아이 나이가 맞나 (3/6)
6. 치료가 성장호르몬 주사 하나인가 (1/6)

## 4. 핵심 메시지

### 05장 — 다축 관리

이 리플렛에서 가장 중요한 장이다. "치료 = 성장호르몬 주사 한 대"라는 통념을 깬다.

```
호르몬       성장호르몬 · 성호르몬 · 갑상선 — 아이마다 다르게
염증         알러지 · 장 염증
수면         성장호르몬이 나오는 시간
영양 · 식욕   먹은 것이 실제로 흡수되도록
운동 · 자세   성장판 자극
```

원장 저서의 프레이밍을 쓴다 — **유전은 바꿀 수 없지만 영양·수면·운동·스트레스는 조절할 수 있다.**

### 숫자

```
치료 기간      평균 3년 미만
희망키 도달     97% 이상
표준 치료 기간  평균 5년 (문헌)
```

### 07~09장 — 해외 환자 절차

부모가 결정하려면 이 흐름이 한눈에 보여야 한다. **도해(다이어그램)로 처리하는 것을 권한다.**

```
[문의]  →  [영문 소견서 발급]  →  [현지에서 X-ray]  →  [화상 상담]
                                                          ↓
                                              [한국 방문 — 당일 하루에 완료]
                                                          ↓
              [6개월치 약]  ·  [매월 화상 상담]  ·  [6~12개월마다 검진]
                                                    (내원 또는 현지 X-ray 전송)
```

## 7. 제약 — 반드시 지킬 것

### 다국어

**같은 레이아웃에 6~9개 언어가 들어간다.** 같은 문장이 언어마다 길이가 30~50% 차이난다.

- **고정 폭·고정 높이 텍스트 박스를 만들지 말 것.** 지금 리플렛이 이것 때문에 폰트를 자동 축소하고 있다.
- 태국어는 성조부호 때문에 **행간이 더 필요**하다.
- 아랍어는 **RTL**이다. 좌우 비대칭 레이아웃은 미러링이 필요하다.
- 단어 중간 줄바꿈 금지(CJK: `word-break: keep-all`).

### 화면

- **폰 우선.** 기준 폭 375px. 여기서 축소 없이 읽혀야 한다.
- 본문 최소 15px. 지금 리플렛은 축소되면 8px 수준으로 떨어진다.

### 인쇄

- A4 (210 × 297mm) 낱장, 단면 기준.
- 장 사이가 페이지 경계와 맞아야 한다. 한 장이 두 페이지에 걸치지 않게.

### 의료광고

- **효과를 보장하는 표현 금지** — "반드시" "완치" "최고"
- **공포 조장 금지**
- 전문의약품 이름을 쓰지 않는다
- ⚠️ 원장은 **소아청소년과 전문의가 아니다.** "전문의"로 표기하지 말 것. 소아 성장·호르몬 진료 15년으로 쓴다.

### 톤

- 화자는 **남성 의사, 격식체.**
- 태국어 종결입자는 `ครับ` (여성형 `ค่ะ/คะ` 금지), 1인칭 `ผม`
- 베트남어 `tôi` 격식체, 중국어 격식체

## 8. 참고 — 웹사이트에서 통한 것

같은 팀이 만든 홈페이지(`dr187growup.com`)에서 검증된 패턴이다.

**긴 이미지에 글자를 굽지 말 것.** 인포그래픽에 텍스트를 넣어 이미지로 만들었더니 폰에서 33% 축소돼 글자가 8px이 됐다. 지금은 아이콘만 이미지로 두고 **글자는 전부 HTML**이다. 리플렛도 같은 원칙으로 간다 — 도해는 선·도형만, 라벨은 텍스트.

**접었다 펴는 구조가 잘 통한다.** 6축 통합 관리를 `<details>` 아코디언으로 만들어 기본은 제목만 보이고 필요한 것만 펼치게 했다. 화면에서는 이 방식이, 인쇄에서는 전부 펼친 상태가 나오면 된다.

**세로형이 가로형보다 낫다.** 와이드 인포그래픽은 폰에서 축소되고, 세로로 쌓은 것은 그대로 읽힌다.

**시설 사진은 가로 스와이프.** 8장을 한 화면에 욱여넣지 않고 옆으로 넘기게 했다. 다음 사진이 살짝 보이게 해서 넘길 수 있다는 걸 알린다.

## 9. 산출물

디자인 단계에서 필요한 것:

1. **13장 각각의 레이아웃 시안** — 폰(375px) 기준
2. **A4 인쇄본에서 각 장이 어떻게 보이는지**
3. **07~09장 절차 도해** — 이 리플렛의 핵심
4. **05장 다축 관리 도해** — 5개 축을 어떻게 보여줄지
5. **타이포 스케일** — 제목/본문/캡션, 다국어 대응 가능한 범위

구현은 **내용(YAML) + 템플릿(HTML) + CSS** 한 벌로, 화면은 흐르고 인쇄는 `@media print`로 A4를 잡는 구조를 예정하고 있다. 시안이 이 구조로 만들 수 있는 형태면 좋다.
